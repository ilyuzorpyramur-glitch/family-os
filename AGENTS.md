# AGENTS.md — правила для coding-агентов

Репозиторий Family OS. Читать перед любой задачей.

## Что это

Семейное приложение: родительский контроль, финансы, запасы, питание, геймификация
и агент OpenClaw. Документация — источник истины по продукту.

## Порядок работы

1. Прочитать `README.md` и релевантный документ в `docs/`.
2. Проверить `docs/ROADMAP.md`: не делаем фичи вне текущей вехи без явного запроса.
3. Изменения схемы данных — только идемпотентным DDL в `apps/api/src/db.ts` + обновление `docs/DATA-MODEL.md`.
4. Решения, меняющие архитектуру, — новый ADR в `docs/DECISIONS/`.
5. Перед PR: `npm run typecheck && npm test`.

## Правила кода

- TypeScript strict, без `any` в публичных API.
- Деньги — целые minor units (`BigInt`/`number` в минимальных единицах), никогда `float`.
- Все запросы к БД фильтруются по `familyId`; для нового модуля — тест на изоляцию.
- Валидация входа — zod-схемы в `packages/shared`.
- Никаких секретов в коде и тестах; только ENV.
- Комментарии — по делу, на русском или английском, но не пересказ кода.

## Запрещено

- Добавлять аналитику, трекеры, рекламные SDK.
- Ослаблять проверки ролей «чтобы заработало».
- Писать в БД из MCP-инструментов напрямую — только через API.
- Менять `SECURITY-PRIVACY.md` без явного согласования.

## Стиль коммитов

`type(scope): summary` — `feat(money): add transfer between accounts`.
Типы: feat, fix, refactor, docs, test, chore, infra.

## Проверка результата

Любая задача считается выполненной, когда:
- код собирается и тесты проходят;
- есть тест на новое поведение (или объяснение, почему нет);
- документация обновлена, если изменились контракты.
