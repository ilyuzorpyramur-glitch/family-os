# apps/web

Веб-панель родителя: Next.js (App Router), Tailwind, shadcn/ui.

## Экраны

- `/` — сводка: бюджет, калории семьи, задания, события guard.
- `/money` — счета, транзакции, бюджеты, импорт.
- `/pantry` — остатки, сроки, список покупок.
- `/nutrition` — дневник и отчёты.
- `/quests` — задания, достижения, награды.
- `/guard` — дети, лимиты, расписания, события.
- `/settings` — семья, роли, устройства, токены агента.

## Принципы UI

- Мобильный первый: 80% использования — с телефона.
- Один экран — один вопрос. Никаких дашбордов «всё сразу».
- Числа крупно, детали — по тапу.
- Тёмная тема по умолчанию.
