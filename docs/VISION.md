# VISION — зачем это нужно

## Проблема

Семья сегодня живёт в 5–7 приложениях: Family Link следит за экраном, банк — за тратами,
Grocy — за холодильником, Lifesum — за калориями, LifeUp — за привычками. Они не знают
друг о друге. Родитель вручную переносит цифры, ребёнок не понимает, за что его ограничивают,
а «умные рекомендации» заканчиваются пуш-уведомлением «вы много тратите».

## Идея

Один домен данных на семью + один агент, который видит связи между ними.

- Купили 2 кг курицы → списалось из бюджета, легло в запасы, появилось в рецептах.
- Ребёнок приготовил ужин по рецепту → продукты списаны, калории записаны, XP начислен.
- Неделя без просрочки задач → бонус к экранному времени, а не абстрактный «бейдж».
- Траты на доставку выросли на 40% → агент предлагает бюджет и рецепты из имеющихся продуктов.

## Персоны

1. **Родитель-администратор.** Ставит правила, смотрит дашборд, утверждает траты и награды.
2. **Ребёнок / подросток.** Видит свои задания, лимиты, карманные деньги; имеет право знать,
   какие данные о нём собираются.
3. **Второй взрослый.** Совладелец бюджета, равные права, отдельный профиль.
4. **Агент OpenClaw.** Не человек, но полноправный участник: читает состояние, предлагает,
   выполняет в рамках выданных разрешений.

## Что берём у референсов

| Источник | Берём | Не берём |
|---|---|---|
| Zen Money | мультивалютность, быстрый ввод, импорт банков, прогноз баланса | закрытость, отсутствие семейной роли |
| Grocy | партии, сроки годности, места хранения | сложность UI и ручной ввод |
| LifeUp | гибкие задания, XP, магазин наград | одиночная модель, нет семьи |
| Lifesum | дневник питания, штрихкоды, нормы | платная стена на базовые функции |
| Family Link | управление устройством на уровне ОС | минимум прозрачности для ребёнка |

## Чего не делаем

- Скрытого мониторинга: чтение переписок, прослушка, кейлоггер, скрытые скриншоты.
- Установки на устройства взрослых без их ведома.
- Продажи и передачи данных третьим лицам. Рекламы нет.
- Медицинских рекомендаций. Калории — бытовой учёт, не диагноз.

## Принципы продукта

1. **Ребёнок — субъект, не объект.** У него есть экран «что обо мне знают» и кнопка «спросить почему».
2. **Правила видны.** Любой лимит объяснён: кто, когда и зачем поставил.
3. **Оффлайн — норма.** Приложение работает без сети, синхронизация догоняет.
4. **Импорт вместо ввода.** Банк, штрихкод, шаблон, голос — но не 20 полей вручную.
5. **Агент предлагает, человек решает.** Деньги и правила меняются только с подтверждением.

## Метрики успеха

- 80% операций попадают в систему без ручного ввода.
- Заполнение дневника питания — ≤ 20 секунд на приём пищи.
- Родитель открывает приложение ≤ 3 раз в день и получает ответы, а не сырые графики.
- Ребёнок выполняет ≥ 60% заданий недели без напоминаний.
