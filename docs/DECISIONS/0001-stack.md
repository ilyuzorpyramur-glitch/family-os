# ADR 0001 — стек

**Дата:** 2026-10-23
**Статус:** принято

## Контекст

Нужны: Android-приложение с глубокими системными правами, веб-панель, API, Telegram-бот
и MCP-сервер для OpenClaw. Команда — один человек + агенты. Сроки важнее академической чистоты.

## Решение

- **Backend:** TypeScript + Fastify + Prisma + PostgreSQL + Redis/BullMQ.
- **Web:** Next.js (App Router) + Tailwind + shadcn/ui.
- **Android:** Kotlin + Compose + Room + Hilt + WorkManager.
- **Агент:** отдельный MCP-сервер на TypeScript.

## Альтернативы

1. **Kotlin Multiplatform (общий домен на Kotlin).** Плюс: один язык, общая логика.
   Минус: web на Compose for Web сырой, скорость разработки ниже, экосистема беднее.
   Отложено до iOS.
2. **NestJS вместо Fastify.** Плюс: структура из коробки. Минус: тяжелее, больше магии.
   Fastify + явные модули проще для агентов и быстрее.
3. **Supabase/Firebase как backend.** Плюс: быстро. Минус: вендор-лок, сложнее двойная
   запись и аудит, приватность данных семьи под вопросом.
4. **Python (Django) backend.** Плюс: админка. Минус: второй язык, нет общего типа с web/ботом.

## Последствия

- Один язык на сервере, вебе и боте → общие типы и схемы (zod).
- Prisma даёт миграции, но требует аккуратности с `BigInt` и `Decimal` для денег.
- Android остаётся отдельным миром; контракт — OpenAPI, генерируем клиент.
