# ROADMAP

Формат: цель → результат → критерий готовности. Оценки в неделях одного разработчика;
с агентом быстрее, но не в разы — тестировать всё равно людям.

## M0 — фундамент (неделя 1) — выполнено

- [x] Репозиторий, документация, модель данных, решения по стеку.
- [x] `apps/api`: Fastify + SQLite, health-check, конфиг, тесты.
- [x] Веб-панель: вход, дашборд, настройки (серверный HTML, без сборки).
- [x] `docker-compose.yml` + `Dockerfile` (один контейнер, том `/data`).
- [x] `AGENTS.md` для coding-агентов.

**Готово, когда:** `docker compose up` поднимает сервер, тесты зелёные. — **готово.**

## M1 — семья и деньги (недели 2–5) — частично

- [ ] identity: семья, пользователи, приглашения, роли, JWT + refresh. *(M1.5; сейчас один admin-токен)*
- [x] money: счета, категории, операции, двойная запись, балансы.
- [x] Импорт Zen Money по токену (официальный API, инкрементальный diff).
- [x] Веб-дашборд: остатки, расходы/доходы месяца, счета, последние операции.
- [ ] Бюджеты и отчёты по категориям в UI.
- [ ] Android: быстрый ввод траты (офлайн-очередь).

**Готово, когда:** семья ведёт бюджет без Excel; баланс сходится с банком до копейки. — **осталось: роли и мобильный ввод.**

## M2 — банки и OpenClaw (недели 6–9) — частично, сделано раньше

## Бэклог идей (не сейчас)

- Голосовой ввод трат через Telegram-voice.
- Распознавание чеков (OCR) и автоматическое сопоставление позиций.
- Умный холодильник/умные весы (Home Assistant).
- Семейный календарь и синхронизация с Google Calendar.
- «Карманные» с виртуальной картой (требует партнёра-эмитента, отдельный проект).

## Риски

| Риск | Влияние | Меры |
|---|---|---|
| Банковские API меняют условия | ломается импорт | адаптеры + CSV как fallback |
| Google ужесточает Device Owner | ломается guard | не полагаться на один API, тесты на новых версиях Android |
| Юридические требования к детским данным | блокировка релиза | минимизация, согласие, прозрачность, локальный режим |
| Расползание скоупа | ничего не готово | жёсткие критерии M1–M2, фичи только после |
