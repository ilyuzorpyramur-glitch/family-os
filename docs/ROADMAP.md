# ROADMAP

Формат: цель → результат → критерий готовности. Оценки в неделях одного разработчика;
с агентом быстрее, но не в разы — тестировать всё равно людям.

## M0 — фундамент (неделя 1)

- [x] Репозиторий, документация, модель данных, решения по стеку.
- [ ] `apps/api`: Fastify + Prisma + Postgres, health-check, конфиг, CI (lint, typecheck, test).
- [ ] `apps/web`: каркас Next.js, вход, пустой дашборд.
- [ ] `infra/docker-compose.yml`: Postgres, Redis, MinIO.
- [ ] `AGENTS.md` для coding-агентов, шаблоны PR и issue.

**Готово, когда:** `docker compose up` + `pnpm dev` поднимают API и web, CI зелёный.

## M1 — семья и деньги (недели 2–5)

- [ ] identity: семья, пользователи, приглашения, роли, JWT + refresh.
- [ ] money: счета, категории, ручные транзакции, двойная запись, балансы.
- [ ] Импорт CSV/OFX + правила категоризации.
- [ ] Веб-дашборд: остатки, расходы по категориям, бюджеты месяца.
- [ ] Android: экран быстрого ввода траты (3 тапа), оффлайн-очередь.

**Готово, когда:** семья из 3 человек ведёт бюджет неделю без Excel; баланс сходится с банком
до копейки на импортированных данных.

## M2 — банки и OpenClaw (недели 6–9)

- [ ] GoCardless Bank Account Data: подключение, consent, ежедневная синхронизация.
- [ ] Monobank (если нужен UA-рынок) + адаптер для ручных выписок.
- [ ] Дедупликация и fuzzy-матчинг операций.
- [ ] `packages/openclaw-plugin`: MCP-сервер, 8–10 инструментов, аудит.
- [ ] Telegram-бот: дайджест, «сколько потратили», подтверждение действий.
- [ ] Автоматизации: превышение бюджета, крупная трата, еженедельный отчёт.

**Готово, когда:** операция из банка появляется в системе без участия человека, а агент
в Telegram отвечает на «сколько мы потратили на еду в этом месяце» корректной цифрой.

## M3 — запасы и питание (недели 10–14)

- [ ] Pantry: товары, места, партии, сроки, списание, список покупок.
- [ ] Штрихкоды: ML Kit + Open Food Facts + локальный кэш.
- [ ] Nutrition: дневник, нормы, рецепты, расчёт БЖУ, фото блюда (ручная порция).
- [ ] Связка: рецепт → списание продуктов → калории.
- [ ] Отчёты: просрочка, «что приготовить», остаток калорий.

**Готово, когда:** сканирование продукта занимает < 5 секунд, а рецепт списывает запасы
без ручных правок.

## M4 — родительский контроль (недели 15–20)

- [ ] Device Owner provisioning (QR/ADB), kid mode.
- [ ] UsageStats, лимиты приложений, расписания, bedtime.
- [ ] Локальный VPN/DNS-фильтр, категории сайтов, свои блок-листы.
- [ ] Запрос времени, одобрение родителем, push.
- [ ] Геозоны и SOS (с явным согласием и индикатором).
- [ ] Защита от удаления, отчёт «что собрано».

**Готово, когда:** ребёнок не может обойти лимит перезагрузкой/сменой времени; родитель
получает уведомление < 10 секунд; экран прозрачности доступен ребёнку.

## M5 — геймификация (недели 21–24)

- [ ] Задания, привычки, подтверждение, XP, уровни, стрики.
- [ ] Достижения и магазин наград (экранное время, карманные).
- [ ] Семейный рейтинг и недельные челленджи.
- [ ] Связка с деньгами: карманные как награда, трата — как событие.

**Готово, когда:** недельный цикл заданий проходится без багов, награда реально влияет
на лимит экранного времени.

## M6 — зрелость (недели 25+)

- [ ] iOS-клиент (оценка KMP или нативная разработка).
- [ ] Полнотекстовый поиск, оффлайн-конфликты, версионирование.
- [ ] Семейный экспорт/импорт, удаление данных, GDPR-процессы.
- [ ] Self-hosted сборка в один клик, бэкапы, мониторинг.
- [ ] Публичный релиз, документация для нетехнических семей.

## Бэклог идей (не сейчас)

- Голосовой ввод трат через Telegram-voice.
- Распознавание чеков (OCR) и автоматическое сопоставление позиций.
- Умный холодильник/умные весы (Home Assistant).
- Семейный календарь и синхронизация с Google Calendar.
- «Карманные» с виртуальной картой (требует партнёра-эмитента, отдельный проект).

## Риски

| Риск | Влияние | Меры |
|---|---|---|
| Банковские API меняют условия | ломается импорт | адаптеры + CSV как fallback |
| Google ужесточает Device Owner | ломается guard | не полагаться на один API, тесты на новых версиях Android |
| Юридические требования к детским данным | блокировка релиза | минимизация, согласие, прозрачность, локальный режим |
| Расползание скоупа | ничего не готово | жёсткие критерии M1–M2, фичи только после |
