# Модуль Quest — геймификация

## Зачем

Правила без мотивации — это полиция. Задания превращают бытовые обязанности в понятную
игру с честными правилами и реальными наградами.

## Механика

- **XP** — за выполненное задание; уровень = `floor(sqrt(xp/50))`, растёт замедляясь.
- **Стрик** — серия дней/недель; ломается при пропуске, но есть «заморозка» (1 в месяц).
- **Достижения** — правила на событиях: `streak_7`, `budget_hero`, `chef_10`, `no_snooze_week`.
- **Награды** — магазин: экранное время, карманные, выбор фильма, поход. Цена в XP или деньгах.
- **Семейный рейтинг** — недельный, сбрасывается; не влияет на базовые права.

## Типы заданий

| Тип | Пример | Подтверждение |
|---|---|---|
| `ONCE` | «Собрать шкаф» | фото или отметка родителя |
| `DAILY` | «Посуда после ужина» | отметка + окно времени |
| `WEEKLY` | «Пылесос в субботу» | фото |
| `HABIT` | «30 минут чтения» | таймер/синхронизация с Guard |

## Жизненный цикл

```
создано → в работе → выполнено (pending) → одобрено (approved) → XP/награда
                                       ↘ отклонено (rejected) с причиной
```

- Автоодобрение — для заданий с объективной проверкой (таймер чтения, шаги).
- Спорные случаи — родитель решает; причина обязательна, ребёнок видит её.

## Анти-абьюз

- Нельзя начислять XP за действия, которые уже вознаграждены деньгами, без явной настройки.
- Лимит XP в день — защита от «фарма» (например, 200 XP).
- Отмена задания после одобрения — только owner, с откатом XP.
- Награда «деньги» создаёт транзакцию `INCOME` на карманный счёт ребёнка.

## Связки

- Guard: награда «+30 минут экрана» меняет лимит на сегодня.
- Money: карманные, штрафы нет (только невыдача бонуса).
- Pantry: задание «приготовить ужин» списывает продукты.
- Nutrition: «неделя без пропусков завтрака» — достижение, не принуждение.

## Тон

Поддерживающий, без стыда. Пропуск — не провал, а данные. Ребёнок может предложить
своё задание и цену награды — родитель утверждает.
