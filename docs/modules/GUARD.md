# Модуль Guard — родительский контроль

## Возможности

| Функция | Как работает | Ограничения |
|---|---|---|
| Дневной лимит экрана | `UsageStatsManager` + локальный счётчик | обход через второй профиль — решается Device Owner |
| Расписание (bedtime, школа) | локальные правила в Room | требует точного времени, проверяем автоперевод часов |
| Лимиты приложений | `AppOps`/overlay + возврат на домашний экран | системные приложения исключены |
| Фильтрация веба | локальный VPN + DNS + блок-листы | не расшифровываем HTTPS; категории — по домену |
| Геозоны | Geofencing API, событие на сервер | только по согласию, история 7 дней |
| SOS | долгое нажатие/кнопка в kid-mode | приоритет над тихими часами |
| Запрос времени | ребёнок просит, родитель одобряет | автоодобрение по правилу — опция |
| Защита от удаления | Device Owner + PIN | аварийный сброс устройства остаётся |
| Прозрачность | экран «что собрано» у ребёнка | обязателен, не отключается |

## device owner provisioning

1. Новое устройство или сброс → экран приветствия.
2. 6 тапов по экрану → QR-провisioning из приложения родителя.
3. `DevicePolicyManager.setDeviceOwner()` — приложение получает права.
4. Установка kid-профиля, политики, PIN родителя.

Для отладки: `adb shell dpm set-device-owner com.familyos.guard/.admin.FamilyDeviceAdmin`.

## Модель угроз (ребёнок)

- Смена времени → сервер сверяет `occurredAt` с NTP, локальный счётчик монотонный.
- Перезагрузка → счётчик восстанавливается из Room + `UsageStats` за день.
- Удаление приложения → запрещено Device Owner.
- Установка обходчиков → блок установки из неизвестных источников, лог попыток.
- VPN-обход → блок создания сторонних VPN-профилей.
- Второй профиль → запрещён политикой.

## Что показываем ребёнку

- Сколько времени осталось, что заблокировано и до какого часа.
- Кнопка «попросить ещё 15 минут» с причиной.
- История собственных запросов и ответов.
- Список данных, которые видит родитель.

## Этика

Не превращаем в слежку. Нет чтения контента, нет скрытых функций, нет «режима невидимки».
Любое усиление контроля — с уведомлением ребёнку.

## Метрики

- Доля лимитов, обойдённых без ведома родителя (цель: 0).
- Медианное время ответа на запрос времени (< 5 мин в активные часы).
- Число ложных срабатываний геозон (< 1 в неделю).
