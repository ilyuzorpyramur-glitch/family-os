# packages/shared

Общие типы и схемы для api, web, bot и MCP.

- zod-схемы запросов/ответов;
- типы домена (`Money`, `Meal`, `Quest`), сгенерированные из Prisma или описанные вручную;
- утилиты: деньги (minor units), даты (Europe/Warsaw), форматирование.

Правило: если схема нужна двум приложениям — она живёт здесь, а не копируется.

Статус: M1.
