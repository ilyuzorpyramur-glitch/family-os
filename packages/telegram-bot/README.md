# packages/telegram-bot

Telegram-интерфейс семьи: grammY + webhook.

## Команды

| Команда | Что делает |
|---|---|
| `/start <code>` | привязка аккаунта к семье |
| `/today` | сводка дня: траты, калории, задания |
| `/spent [период]` | расходы по категориям |
| `/budget` | исполнение бюджетов |
| `/quests` | мои задания и кнопки «выполнено» |
| `/approve <id>` | подтверждение действия агента |
| `/mute <часы>` | тихий режим |

## Правила

- Личные финансы — только в личку, не в группу.
- Группа семьи — уведомления и совместные списки покупок.
- Кнопки вместо ввода команд там, где возможно.
- Все действия — через API, своей логики нет.
