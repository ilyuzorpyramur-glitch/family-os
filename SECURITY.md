# Security Policy

## Supported versions

Проект в разработке; поддерживается только `main`.

## Reporting

Не открывайте публичный issue для уязвимостей. Напишите владельцу репозитория
через GitHub Security Advisories (вкладка Security → Report a vulnerability).

Мы отвечаем в течение 72 часов и указываем срок исправления.

## Scope

- API: авторизация, изоляция семей, IDOR, rate limit.
- Android: обход лимитов, повышение прав, утечка данных ребёнка.
- Агент: выход за scope, обход confirm-flow, инъекции в инструменты.
- Инфраструктура: секреты в репозитории, конфигурация хранилища.

## Вне scope

- Атаки, требующие физического доступа к разблокированному устройству родителя.
- Сторонние сервисы (банки, Open Food Facts) — сообщайте им напрямую.
